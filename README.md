# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 卸油互锁台

在油站页内登记卸油单（油罐、油品、来油体积、计划时段、押运员），并驱动开工 / 完工 / 复核闭环：

- **整单拒绝**：时段重叠、罐容不足、油品不符、站点尚在营业或存在待复核单时拒绝登记，原排期、库存和站点状态不变；仅因时段重叠被挡的单转入候单。
- **取消补位**：取消已排期单释放油罐与时段，候单按提交顺序自动补位。
- **开工 / 完工**：开工把站点转为暂停营业；完工按实收体积入库（同步站点库存摘要）并恢复站点原状态。
- **短溢复核**：实收与来油之差超过 50L 进入待复核，复核归档前该站不得再排新单。

业务代码分三个文件，无新增依赖、无后端：

| 文件 | 职责 |
| --- | --- |
| `src/unloading/rules.ts` | 规则：状态机、登记校验、短溢判定等纯函数 |
| `src/unloading/store.ts` | 状态：响应式状态与登记/取消/开工/完工/复核动作 |
| `src/unloading/storage.ts` | 持久化：localStorage 读写与种子油罐 |
