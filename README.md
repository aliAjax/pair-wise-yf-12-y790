# 卸油互锁台（油站网点扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（不加依赖、无后端，数据存浏览器 localStorage）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

登记卸油单需填写：油罐、油品、来油体积（L）、计划时段、押运员。

互锁校验（`src/business/rules.ts`，纯函数）：

1. **时段重叠**：同一油罐与已排期 / 作业中单据的计划时段重叠，不锁罐，按提交顺序（seq）进入**候单**；
2. **罐容不足**：当前库存 + 已排期预留 + 本来油体积超过罐容，**整单拒绝**；
3. **油品不符**：单据油品与油罐标定油品不一致，**整单拒绝**；
4. **站点尚在营业**：站点状态为「营业中」不得排期，**整单拒绝**（可在看板先手工置为暂停营业，候单会自动补位）；
5. **待复核封锁**：站点存在「待复核」短溢单时不得再排新单，候单也不得补入该站。

硬拒绝时原排期、库存、站点状态均不变。取消候单 / 已排期单据释放油罐与时段，随后候单**按提交顺序**扫描：可通过者补入排期，头单仍被拦截则停止扫描、后续单据不越位。

流转操作：

- **开工**：仅已排期可开工；站点转为「暂停营业」，记录原状态；
- **完工**：填写实收体积。实收与来油计划之差（短/溢）在 50L（含）以内：按实收体积入库、恢复站点原状态、释放罐位并触发补位；超过 50L：单据进入**待复核**，不入库、站点保持暂停营业，全站封锁新排期；
- **复核**：确认体积后补入库并恢复站点状态、解除封锁、触发补位（超罐容仍拒绝入库）。

## 文件划分

| 文件 | 职责 |
| --- | --- |
| `src/business/rules.ts` | 互锁规则、状态枚举、纯函数判定（时段重叠 / 罐容 / 油品 / 营业状态 / 短溢容差） |
| `src/business/state.ts` | 响应式状态与单据流转编排（提交、取消、补位、开工、完工、复核、站点状态） |
| `src/business/persistence.ts` | localStorage 读写、版本校验、演示种子数据 |
| `src/App.vue` | 互锁台界面：站点油罐看板、登记表、单据流转列表 |

localStorage key：`hxwlfront-21-unload-interlock`，页面右上角「恢复演示数据」可一键重置。
